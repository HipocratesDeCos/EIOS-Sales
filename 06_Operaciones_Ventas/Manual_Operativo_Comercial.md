# Manual operativo comercial

## Evaluar

1. Seleccionar perfil vigente y verificar `parameter_set_id`.
2. Introducir literalmente producto/servicio, cantidad, cliente, precio/condiciones, suministro y pago.
3. Solicitar evaluación. Ante ⚪, aportar el dato solicitado, no una estimación sin etiquetar.

## Negociar

1. Presentar opción o condición concreta.
2. Registrar respuesta del cliente sin reinterpretarla.
3. Para una concesión, registrar contrapartida comprobable.
4. Reevaluar: mismo `trace_id`, nueva revisión.

## Cerrar

El comercial autorizado registra decisión y motivo. Aceptar comercialmente no ejecuta ERP. Un 🔴 no se vuelve venta manualmente: requiere hechos/condiciones nuevos y reevaluación; el historial se conserva. ⚪ no es rechazo ni permiso para asumir: queda pendiente de los elementos enumerados.
