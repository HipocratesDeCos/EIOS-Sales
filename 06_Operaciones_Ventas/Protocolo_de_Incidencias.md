# Protocolo de incidencias

| Incidencia | Tratamiento |
| --- | --- |
| Fuente no disponible/caducada | Evidencia ausente/caducada y ⚪ donde sea necesaria. |
| Dato corregido | Evento de corrección y reevaluación; nunca editar historial. |
| Resultado inesperado | Conservar Trace ID, entradas, versiones y evidencia; escalar a responsable de reglas. |
| Dato fabricado sospechado | Detener, aislar y sustituir solo por fuente verificable. |
| Intento de eludir 🔴 | No modificar color manualmente; exigir cambio y revisión. |
| Cambio de parámetros | Publicar nuevo perfil versionado; no aplicar retroactivamente. |
